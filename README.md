# Olist 이커머스 데이터 분석 프로젝트

## 1. 프로젝트 소개

브라질 이커머스 플랫폼 Olist의 공개 데이터를 활용해 주문, 고객, 상품, 결제, 리뷰, 배송 데이터를 분석한 프로젝트입니다.

총 99,440건의 주문 데이터를 SQLite 데이터베이스에 적재하고, SQL과 Python을 활용해 주문 흐름, 매출 변화, 고객 구매 패턴, 상품 카테고리 성과, 리뷰 점수, 배송 성과를 분석했습니다.

단순한 수치 확인에 그치지 않고, 고객 재구매율, 배송 지연과 리뷰 점수의 관계, 카테고리별 주문·매출 차이를 비즈니스 관점에서 해석하는 데 초점을 두었습니다.

## 3. 분석 질문

이 프로젝트에서는 다음 질문을 중심으로 데이터를 분석했습니다.

1. 월별 주문량과 매출은 어떤 흐름을 보이는가?
2. 주문량과 매출이 가장 높았던 시점은 언제인가?
3. 고객의 재구매 비율은 어느 정도인가?
4. 배송 지연 여부는 리뷰 점수와 어떤 관계가 있는가?
5. 리뷰 점수는 어떤 분포를 보이는가?
6. 상품 카테고리별 주문량과 매출은 어떻게 다른가?
7. 주문 수가 많은 카테고리와 매출이 높은 카테고리는 일치하는가?

## 7. 주요 분석 결과

### 7-1. 주문 및 매출 분석

분석 기간은 2016년 9월 4일부터 2018년 10월 17일까지이며, 전체 주문 수는 99,440건입니다.

월별 주문 수와 매출을 분석한 결과, 주문 수와 매출이 모두 2017년 11월에 가장 높게 나타났습니다.

| 항목 | 결과 |
|---|---:|
| 전체 주문 수 | 99,440건 |
| 분석 기간 | 2016-09-04 ~ 2018-10-17 |
| 총 매출 | 16,008,872.12 |
| 최고 주문 월 | 2017-11 |
| 최고 주문 월 주문 수 | 7,544건 |
| 최고 매출 월 | 2017-11 |
| 최고 매출 월 매출 | 1,194,882.80 |

2017년 11월은 주문 수와 매출이 동시에 가장 높게 나타난 시점으로, 특정 기간의 주문 증가가 실제 매출 증가와도 연결된 것으로 확인했습니다.

### 7-2. 재구매 고객 분석

`customer_unique_id`를 기준으로 고객별 주문 횟수를 집계했습니다.

총 96,096명의 고유 고객 중 93,099명은 1회 구매 고객, 2,997명은 재구매 고객으로 확인되었습니다. 재구매 고객 비율은 3.12%로 낮게 나타났으며, 고객당 평균 주문 횟수는 1.03회였습니다.

| 항목 | 결과 |
|---|---:|
| 고유 고객 수 | 96,096명 |
| 1회 구매 고객 수 | 93,099명 |
| 재구매 고객 수 | 2,997명 |
| 1회 구매 고객 비율 | 96.88% |
| 재구매 고객 비율 | 3.12% |
| 고객당 평균 주문 횟수 | 1.03회 |

대부분의 고객이 1회 구매에 그치고 있어, 신규 고객 유입뿐 아니라 재구매 유도와 고객 유지 전략이 중요하다고 판단했습니다.

---

### 7-3. 배송 분석

주문일과 실제 배송 완료일을 기준으로 평균 배송 소요일을 계산하고, 예상 배송일보다 늦게 배송된 주문을 배송 지연 주문으로 정의했습니다.

분석 결과 평균 배송 소요일은 12.56일이었고, 배송 지연 주문은 6,535건으로 전체의 6.77%를 차지했습니다.

| 항목 | 결과 |
|---|---:|
| 평균 배송 소요일 | 12.56일 |
| 배송 지연 주문 수 | 6,535건 |
| 배송 지연율 | 6.77% |
| 정상 배송 평균 리뷰 점수 | 4.29점 |
| 지연 배송 평균 리뷰 점수 | 2.27점 |

정상 배송 주문의 평균 리뷰 점수는 4.29점인 반면, 지연 배송 주문의 평균 리뷰 점수는 2.27점으로 나타났습니다.  
이를 통해 배송 지연이 고객 만족도에 부정적인 영향을 줄 가능성을 확인했습니다.

### 7-4. 리뷰 분석

전체 리뷰 점수의 평균은 4.09점으로 나타났습니다.  
리뷰 점수 5점 비율은 57.78%, 1점 비율은 11.51%였습니다.

| 항목 | 결과 |
|---|---:|
| 평균 리뷰 점수 | 4.09점 |
| 5점 리뷰 비율 | 57.78% |
| 1점 리뷰 비율 | 11.51% |

전체적으로 긍정 리뷰 비중이 높지만, 1점 리뷰도 11.51% 존재해 낮은 리뷰가 발생하는 원인을 추가로 확인할 필요가 있습니다.  
특히 배송 지연 주문의 평균 리뷰 점수가 낮게 나타난 점을 고려하면, 배송 경험은 리뷰 점수를 설명하는 주요 요인 중 하나로 볼 수 있습니다.

## 8. 핵심 인사이트

### 1) 재구매율이 낮아 고객 유지 전략이 중요함

총 96,096명의 고유 고객 중 재구매 고객은 2,997명으로, 전체의 3.12%에 그쳤습니다.  
반면 1회 구매 고객은 93,099명으로 96.88%를 차지했습니다.

이를 통해 Olist 데이터에서는 대부분의 고객이 1회 구매에 그치고 있음을 확인했습니다.  
따라서 신규 고객 유입뿐 아니라 재구매 유도, 고객 유지, 리텐션 관점의 분석이 필요하다고 판단했습니다.

### 2) 배송 지연은 리뷰 점수 하락과 뚜렷하게 연결됨

정상 배송 주문의 평균 리뷰 점수는 4.29점이었지만, 지연 배송 주문의 평균 리뷰 점수는 2.27점이었습니다.  
두 그룹 간 평균 리뷰 점수 차이는 2.02점으로, 배송 지연 여부가 고객 만족도에 큰 영향을 줄 가능성을 확인했습니다.

이커머스 서비스에서는 상품 자체뿐 아니라 배송 경험도 고객 만족도를 결정하는 중요한 요소로 작용할 수 있습니다.

### 3) 주문 수와 매출은 함께 봐야 함

2017년 11월은 주문 수 7,544건, 매출 1,194,882.80으로 주문 수와 매출이 모두 가장 높게 나타난 월이었습니다.  
주문량 분석만으로는 실제 비즈니스 성과를 충분히 판단하기 어렵기 때문에, 결제 금액 기준의 매출 흐름을 함께 확인해야 합니다.

### 4) 카테고리 성과는 주문량과 매출을 함께 비교해야 함

주문 수 기준 1위 카테고리는 `bed_bath_table`이었지만, 매출 기준 1위 카테고리는 `health_beauty`였습니다.  
이는 판매량이 높은 카테고리와 매출 기여도가 높은 카테고리가 다를 수 있음을 보여줍니다.

따라서 카테고리 성과를 판단할 때는 주문 수, 매출, 리뷰 점수 등 여러 지표를 함께 고려해야 합니다.

### 5) 여러 테이블의 관계 이해가 분석의 출발점이 됨

Olist 데이터는 주문, 고객, 상품, 결제, 리뷰, 배송 정보가 여러 테이블에 나뉘어 있어 단일 테이블만으로는 충분한 분석이 어렵습니다.  
따라서 주문 ID, 고객 ID, 상품 ID 등 주요 key를 기준으로 테이블 간 관계를 먼저 이해하는 과정이 필요했습니다.

이 프로젝트를 통해 데이터 분석에서는 분석 결과를 도출하기 전에 데이터 구조를 먼저 이해하는 과정이 중요하다는 점을 배웠습니다.

특히 주문, 고객, 상품, 결제, 리뷰처럼 여러 테이블로 나뉜 데이터를 분석할 때는 어떤 key를 기준으로 데이터를 연결할지, 중복이나 누락이 분석 결과에 어떤 영향을 줄 수 있는지 확인하는 과정이 필요했습니다.

또한 SQL과 Python을 함께 활용하면서, SQL은 테이블 간 JOIN과 집계에 강점이 있고 Python은 전처리, 시각화, 결과 해석에 강점이 있다는 점을 경험했습니다. 이를 바탕으로 데이터를 단순히 정리하는 데서 끝내지 않고, 비즈니스 질문에 답할 수 있는 형태로 분석 결과를 정리하는 것이 중요하다고 느꼈습니다.
