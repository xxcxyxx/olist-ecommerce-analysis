Olist 이커머스 데이터 분석 프로젝트
프로젝트 개요

이 프로젝트는 Brazilian E-Commerce Public Dataset by Olist를 활용하여
주문, 고객, 상품, 판매자, 결제, 리뷰 데이터를 분석하는 이커머스 데이터 분석 프로젝트입니다.

Python, SQLite, Jupyter Notebook 환경에서 데이터를 적재하고,
SQL 중심의 탐색적 데이터 분석(EDA)을 통해 주문 흐름, 배송 성과, 고객 특성, 상품 카테고리 성과, 판매자 분포, 결제 패턴, 리뷰 경향을 파악하는 것을 목표로 합니다.

단순히 수치를 확인하는 데 그치지 않고,
분석 결과를 실제 비즈니스 관점에서 해석하고 인사이트로 연결하는 데 중점을 두었습니다.

프로젝트 진행 흐름
01. 환경 설정

Jupyter Notebook, SQLite, 필요한 라이브러리 설치 및 실행 환경을 설정합니다.

02. 데이터 적재

원본 CSV 데이터를 불러와 SQLite 데이터베이스에 저장하고,
분석에 사용할 수 있는 테이블 구조를 구성합니다.

03. 전체 데이터 개요 파악

전체 테이블 구조와 각 테이블의 크기, 주요 컬럼을 확인하며
데이터 간 관계를 파악하고 분석 방향을 정리합니다.

04. 주문 데이터 분석

주문 테이블을 중심으로 다음 내용을 분석합니다.

전체 주문 수
주문 상태 분포
월별 / 일별 주문 추이
주문 승인, 배송 시작, 배송 완료까지의 소요 시간
예상 배송일 대비 지연 배송 비율
주문 상태별 결측치 확인
05. 고객 데이터 분석

고객 데이터를 바탕으로 다음 내용을 분석합니다.

고객 수 및 지역 분포
고객 1인당 주문 수
재구매 고객 비율
고객 구매 패턴
06. 상품 데이터 분석

상품 및 카테고리 데이터를 중심으로 다음 내용을 분석합니다.

카테고리별 판매 건수
카테고리별 매출 기여도
상품 특성(크기, 무게 등) 확인
많이 팔리는 상품군과 매출 기여 상품군 비교
07. 판매자 데이터 분석

판매자 데이터를 바탕으로 다음 내용을 분석합니다.

판매자 수 및 지역 분포
판매자별 주문 수
상위 판매자 집중도
판매자 성과 차이
08. 결제 데이터 분석

결제 데이터를 중심으로 다음 내용을 분석합니다.

결제 수단 분포
할부 결제 비율
결제 금액 패턴
주문 금액과 결제 방식의 관계
09. 리뷰 데이터 분석

리뷰 데이터를 활용해 다음 내용을 분석합니다.

리뷰 점수 분포
배송 지연과 리뷰 점수의 관계
특정 판매자 / 카테고리와 리뷰 만족도의 연관성
10. 최종 인사이트 정리

전체 분석 결과를 바탕으로 핵심 인사이트를 정리하고,
이커머스 운영 관점에서 활용 가능한 개선 아이디어를 제안합니다.

핵심 분석 질문

주문 수는 시간에 따라 어떻게 변하는가?

어떤 결제 방식이 가장 많이 사용되는가?
