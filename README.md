# Olist 이커머스 데이터 분석 프로젝트

## 1. 프로젝트 소개

브라질 이커머스 플랫폼 Olist의 공개 데이터를 활용해 주문, 고객, 상품, 판매자, 결제, 리뷰 데이터를 분석한 프로젝트입니다.

원본 CSV 데이터를 SQLite 데이터베이스에 적재하고, SQL과 Python을 활용해 데이터 구조를 확인한 뒤 탐색적 데이터 분석(EDA)을 수행했습니다. 단순히 수치를 확인하는 데 그치지 않고, 주문 흐름, 배송 성과, 고객 구매 패턴, 상품 카테고리 성과, 판매자 분포, 결제 방식, 리뷰 경향을 비즈니스 관점에서 해석하는 것을 목표로 했습니다.

이 프로젝트는 데이터 분석 역량을 중심으로, 데이터 적재와 테이블 구조 이해, SQL 기반 집계, Python 기반 시각화, 분석 결과 문서화 과정을 함께 포함한 포트폴리오 프로젝트입니다.

## 3. 분석 목적

이 프로젝트에서는 이커머스 서비스에서 발생하는 데이터를 기반으로 다음 질문에 답하고자 했습니다.

- 월별 주문량과 매출 흐름은 어떻게 변화하는가?
- 고객의 재구매 비율은 어느 정도이며, 구매 빈도는 어떻게 분포하는가?
- 배송 지연 여부는 리뷰 점수에 영향을 주는가?
- 지역별 주문은 어디에 집중되어 있는가?
- 상품 카테고리별 주문량, 매출, 리뷰 점수는 어떤 차이를 보이는가?
- 판매자별 주문 처리 규모와 성과는 어떻게 다른가?
- 결제 방식에 따라 주문 특성은 어떻게 달라지는가?

## 8. 핵심 인사이트

### 1) 1회 구매 고객 비중이 높게 나타남
`customer_unique_id` 기준으로 고객별 주문 횟수를 집계한 결과, 대부분의 고객이 1회 구매에 그치는 것으로 나타났습니다.  
따라서 단순 신규 고객 유입뿐 아니라 재구매 유도 전략이 중요하다고 판단했습니다.

### 2) 배송 경험은 리뷰 점수와 연결될 가능성이 있음
예상 배송일과 실제 배송 완료일을 비교해 배송 지연 여부를 정의하고, 지연 여부에 따른 리뷰 점수를 비교했습니다.  
배송 지연 주문은 고객 만족도에 부정적인 영향을 줄 가능성이 있어, 배송 품질 관리가 리뷰 개선에 중요한 요소로 해석됩니다.

### 3) 지역별 주문 집중도가 존재함
고객 지역 정보를 기준으로 주문 수를 집계한 결과, 특정 지역에 주문이 집중되는 경향을 확인했습니다.  
이는 지역별 물류 운영, 배송 리드타임 관리, 마케팅 전략 수립 시 함께 고려할 수 있는 요소입니다.

### 4) 상품 카테고리별 성과 차이가 뚜렷함
카테고리별 주문량, 매출, 리뷰 점수를 비교한 결과, 판매량이 높은 카테고리와 고객 만족도가 높은 카테고리가 항상 일치하지는 않았습니다.  
따라서 카테고리 성과를 평가할 때 단순 판매량뿐 아니라 리뷰 점수와 배송 성과를 함께 확인할 필요가 있습니다.

### 5) SQL과 Python의 역할을 분리해 분석 효율을 높임
SQL은 여러 테이블 간 JOIN과 집계 분석에 활용했고, Python은 데이터프레임 처리, 시각화, 결과 해석에 활용했습니다.  
이를 통해 데이터 추출과 분석 과정을 분리하고, 분석 흐름을 재현 가능하게 정리했습니다.

## 12. 배운 점

이 프로젝트를 통해 데이터 분석에서는 시각화나 모델링보다 먼저 데이터 구조를 이해하는 과정이 중요하다는 점을 배웠습니다.

특히 주문, 고객, 결제, 리뷰처럼 여러 테이블로 나뉜 데이터를 분석할 때는 어떤 key를 기준으로 연결할지, 중복이나 누락이 분석 결과에 어떤 영향을 줄 수 있는지 확인하는 과정이 필요했습니다.

또한 SQL과 Python을 함께 활용하면서, SQL은 데이터 추출과 집계에 강점이 있고 Python은 전처리, 시각화, 해석에 강점이 있다는 점을 경험했습니다. 이를 바탕으로 데이터를 단순히 정리하는 데서 끝내지 않고, 비즈니스 질문에 답할 수 있는 형태로 분석 결과를 정리하는 것이 중요하다고 느꼈습니다.
